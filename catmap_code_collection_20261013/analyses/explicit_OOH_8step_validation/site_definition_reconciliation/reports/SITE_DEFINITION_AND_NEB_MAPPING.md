# 八步显式过氧氢中间体：位点定义纠正与 NEB 接入判定

## 当前结论

撤回上一版将化学片段数量设置为共吸附构型 `n_sites=3/4/3/2` 的做法。该设置没有几何占位依据，不能用作正式模型，也不继续在其上提高求根精度。旧输入和失败运行记录仅作历史留存，不代表已确认的物理模型。

本次实际调用本机 CatMAP 0.3.1 的 `ReactionModel`、`parse()`、`verify()`、`get_rxn_energy()` 和 `MeanFieldSolver.site_string_list()`。没有调用 `run()`、稳态、TOF 或 DRC，没有复核 Gibbs 热修正。

## 必须分开的三种计数

|概念|本次基准|证据边界|
|---|---|---|
|化学阶段|原始八阶段：过氧化氢吸附/活化、烯烃吸附、氧转移、环氧物脱附、氢转移、水形成/脱附|化学反应路径组织|
|CatMAP 基元表达式|原始输入恰为8条；未来确有独立构型连接时才增加|不等于真实位点数|
|表面有效位点占据|原始九种稳定吸附物默认各 `n_sites=1`|现有平均场格点约定，不是所有物种真实几何占位已经验证|

共吸附态包含几个化学片段，不能据此推出占据几个吸附格点。两个过渡态不作为稳态覆盖度项。

原始基准位点式为：

```math
\theta_*+\theta_{\mathrm{H_2O_2}}+\theta_{\mathrm{H_a}}+\theta_{\mathrm{H_b}}
+\theta_{\mathrm{OOH}}+\theta_{\mathrm{C_6H_{12}}}+\theta_{\mathrm{C_6H_{12}O}}
+\theta_{\mathrm{O}}+\theta_{\mathrm{OH}}+\theta_{\mathrm{H_2O}}=1.
```

两个原始库存不变量均在实际官方解析得到的计量矩阵上验证为零：

```math
I_1=\theta_{\mathrm{H_a}}-\theta_{\mathrm{OOH}}-\theta_{\mathrm{OH}}-\theta_{\mathrm O},\qquad
I_2=\theta_{\mathrm{H_b}}-\theta_{\mathrm O}.
```

## 实测发现的实现问题

本机 `model.py:1039–1045` 用 `n_sites` 检查形式位点守恒，但 `solvers/mean_field_solver.py:483–495` 的空位表达式虽读取该属性，实际仍为 `1-sum(theta)`，不乘该权重。本次仅在内存中将 OOH 的元数据从1改为3后，生成的空位表达式保持不变；恢复后未求解。

构造测试：九个物种各覆盖0.01，原生表达式得到空位0.91，而假设 OOH 权重3的加权值为0.89。这是接口行为测试，不是科研覆盖度。不能把“位点检查通过”等同于“多位点动力学已正确实现”。上一版加权覆盖度参数化与原生空位表达式不能当作一致实现。此结论仅针对已记录哈希的本机源码，不修改安装包。

## 原始八步与真实 NEB 的接入

|路径|完整 NEB ΔG/eV|原始独立态 ΔG/eV|独立态−NEB/eV|真实局部正/逆差值/eV|
|---|---:|---:|---:|---|
|氧转移，第4阶段|−0.239686|+1.8006475|+2.0403335|0.556344 / 0.796030|
|后续氢转移，第6阶段|−0.480580|−2.0620670|−1.5814870|0.225994 / 0.706574|

已用原始能量文件逐项核对复用表中九种稳定态和两个旧 TS 条目相同。旧 TS 条目标注为 `NEB_forward_TS_minus_IS_mapped`，不是完整 NEB TS 的直接形成能。官方 `get_rxn_energy()` 对旧表给出的有效正/逆势垒分别是：第4步1.8006475/0，第6步0.225994/2.288061 eV。这里的0是端点最高态处理结果，不是独立 DFT 零势垒证据。

完整 NEB1 含旁观 H_a 和烯烃/过氧氢反应体系，完整 NEB2 含 H_a、H_b、O。H_a 在反应计量两边抵消，不代表其构型能量可以作为无相互作用的独立项相减。

对同一个热力学反应必须满足：

```math
\Delta G_f^{\ddagger}-\Delta G_r^{\ddagger}=G_{\mathrm{FS}}-G_{\mathrm{IS}}.
```

因此保留原始独立态端点时，不可能同时保留完整 NEB 的正、逆局部势垒；改位点数也不能改变此恒等式。不能将上述差值当成 TS 修正。

## 最小方案与仍需的证据

1. 原始八步、九种稳定态及显式 OOH 保持为基准；本次不新增共吸附步骤，不生成替代正式输入。
2. 优先核实完整 NEB 端点与独立态组合对应的局部吸附构型/有效格点关系。既有结构审计发现的 XSD/CIF 元素组成只支持片段组成，尚未建立其与实际计算构型的一一对应，不能由此导出格点数量。无需重复计算 Gibbs。
3. 若它们是不同物理构型，才引入独立共吸附状态。需要该状态的几何足迹/允许邻域及独立态进入、离开该构型的连接动力学。已有端点 Gibbs 可给连接自由能，不提供独立连接势垒。
4. 可优先核实并减少连接边：完整 NEB1 终态→完整 NEB2 初态+气相环氧物，端点自由能+0.811237 eV；完整 NEB2 终态→吸附水，−0.601109 eV。这两个已有端点差不是活化能，也不证明结构同一性。
5. 官方相互作用模型可用于有数据支持的非加和相互作用；目前两个端点差不能唯一确定所有稳定态/TS的构型依赖相互作用，故本次不拟合相互作用参数代替缺失证据。

正式 Ti–Co 稳态/TOF/DRC 尚未通过模型门控；不把旧八步 provisional 根或九反应候选结果升级为正式结果。需要补充的是结构—格点映射及确属不同状态时的连接动力学，不是热修正或重新计算全部 DFT。端点近似仍只能是明确授权的条件模型，不能自动解决几何定义。确认后先 Ti–Co 的同库存类、同分支稳态和官方 DRC，再逐位点独立映射推广至14位点，不移植 Ti–Co 的能量差。

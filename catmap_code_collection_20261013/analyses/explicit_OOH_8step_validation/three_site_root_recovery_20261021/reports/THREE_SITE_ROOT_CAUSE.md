# Ti–Mo、Ti–W、Ti–Ta 八步 CatMAP 求根恢复结果

## 结论

- **Ti–Mo：`NUMERIC_PASS`（科研状态仍为 `PROVISIONAL`）**。CatMAP 原生稳态方程在独立数值初猜经 SciPy `least_squares` 定位后，由 CatMAP `NewtonRoot` 高精度抛光得到根；随后 250 位、交替 ±0.01 logit 初值的 CatMAP 独立重解也复现。既非证据支持的物理无稳态，也不是把未收敛根靠放宽阈值纳入。
- **Ti–W：`NUMERIC_FAIL`**。有限搜索只能到达极端零空位边界候选。该候选局部归一化残差不满足稳态门槛，数值 Jacobian 数值秩退化（秩估计 1/7、最小奇异值为 0），不得输出 TOF。
- **Ti–Ta：`NUMERIC_FAIL`**。有限搜索的最佳候选仍有约 `1` 的局部归一化稳态残差，最大绝对物种残差约 `4.20×10^7`；Jacobian 条件数约 `1.10×10^23`。不是可接受稳态，不能报告 TOF。

## 固定输入及复用范围

科学模型预检结果 `MODEL_CONTRACT=PASS`：CatMAP 0.3.1；原始八步显式 OOH 模型；9 个稳定吸附态、2 个过渡态；333.15 K；`pressure_mode='static'`；储库值与正式模型一致。模型 SHA-256：`86115cefb7784fe28ab519271cdfaf0e308b6f6e3a8308b1e90e4318cb497cfe`；能量输入 SHA-256：`55ad4e94d9c603b6705ec8c92630c9a1ceff5859cf69865145152375e203ca30`。

复用了 `multisite_conditional_replay_20261021` 的失败记录与模型探针，以及 `numerical_gate_audit_20261021` 的逐物种局部通量门控和 Ti–Zr 经验。没有重新求解既有 11 个根，没有改动 `.mkm`、能量、NEB、温度、储库、速率表达式、位点数或库存类。

## 有限恢复方法

每个位点各尝试至多 6 个来自既有已收敛位点的零库存根种子和 3 个均匀 logit 初值；CatMAP `NewtonRoot` 每种种子最多 35 步。若局部 Newton 停止在驻点，最多再执行一次有界 SciPy `least_squares`（220 次函数评估）只用于寻找数值初猜；最终候选仍必须由 CatMAP 0.3.1 的 `steady_state_function` 与 `NewtonRoot` 验证。保持参数化约束 `I1=I2=0` 和位点归一化。SciPy 不用于速率、TOF 或最终稳态验收。

局部验收采用每个独立物种的 `|dθ_i/dt| / Σ_j |ν_ij|(r⁺_j+r⁻_j) ≤ 1e-12`；并检查非负覆盖度、位点和、不变量、净反应流、产物 TOF 重建及跨精度复现。5 ppm 门槛未改变。

## Ti–Mo 通量与重复性

CatMAP 官方 `get_rxn_rates` 的8步净速率均为 `2.7472772072623909151×10⁻⁶ s⁻¹`，相对循环通量离散约 `8.97×10⁻⁴²`；产物气相 TOF 与第5步脱附净速率相等。正逆方向通量由 CatMAP `rate_equation_term` 生成的质量作用表达式在任意精度下求值，并与官方净速率逐项比较，最大绝对差约 `7.3×10⁻³⁷⁴`。因此该位点正逆相消已显式计算，未使用会转为 Python float 的 `get_directional_rates` 作减法。

## 是否与 Ti–Zr 的早停问题相同

**Ti–Mo 的失败原因并非已经证实与 Ti–Zr 相同的早停。** 旧脚本确有 `<1e-50` 迭代退出条件，但三个失败位点保存的尝试显示更主要的问题是初值使 CatMAP `NewtonRoot` 早早驻点、Jacobian 数值奇异或边界退化；旧日志未保存足够完整的根以证明曾有一个接近稳态、只被阈值截断的根。Ti–Mo 新根依赖找到更好的初猜。Ti–W 的极小缩放残差候选仍被逐物种通量门控否决；Ti–Ta 则仍有量级为1的局部残差。

## 输入异常及科研边界

三个点都沿用各自原始 NEB/Gibbs 输入。已知异常继续保留：Ti–Mo NEB2 TS−IS `−0.012820 eV`、Ti–W NEB1 TS−IS `−0.566651 eV`、Ti–Ta NEB1 TS−IS `−1.174636 eV`。不得把数值收敛称为真实过渡态物理验证。此轮没有运行 DRC；Ti–W、Ti–Ta 无合格根，也不具备 DRC 基线。

# DRC 差异的能量—速率机制核查：结论

## 1. 主导吸附态为何可能出现 X≈−3θ？

**结论（CONFIRMED_NUMERIC）：** 在主导态 DRC 两种扰动均通过的 11 个位点中，8 个的 `σ_eff=-X_dom/θ_dom` 落在约 2.993–3.005；其余代表偏离为 Ti–Fe≈2.000、Ti–Mn≈2.608、Ti–Re≈2.823。它是固定模型和工况下的样本数值规律。

**数学判断（MODEL_DERIVED）：** DRC 定义为 `X_i=-kBT·d ln(TOF)/dG_i`；稳态覆盖度满足 `F(θ,G)=0`，因此覆盖度响应由 `dθ/dG_i=-(∂F/∂θ)^{-1}(∂F/∂G_i)`（在库存约束子空间上）决定。CatMAP 位点守恒只给出覆盖度总和约束，不给出 `X_i=-3θ_i` 恒等式。速率质量作用幂次也没有统一的 3 倍主导覆盖度因子。故目前不能从方程严格推出该近似，严格来源未建立。

**合理解释边界（CONDITIONAL_INTERPRETATION）：** 这些位点在特定工况下存在占位/通量敏感性组合，使 `-X_dom/θ_dom` 数值接近3；Fe/Mn/Re 的偏离及多个 DRC 非零证明该比例不是普适单态占位定律。不能解释为三个金属原子或三位点协同。

## 3. OOH* 能量—速率常数—完整 DRC 的联系

在 333.15 K，单个包含 OOH_s 的反应态自由能变化会改变对应反应的端点/TS 最高态分支；若分支不切换，CatMAP TST 常数的局部对数斜率约为 `1/(kBT)=34.83 eV⁻¹` 或其相反数，取决于 OOH_s 位于控制态的哪一侧。固定覆盖度直接斜率不是完整 DRC，因为完整 DRC 包括约束稳态下覆盖度重排。

- Ti–Co：既有 OOH DRC=-0.499737/-0.499735（h=.005/.010）；固定覆盖度时 R2 与 R4 的 `dln kf/dG_OOH` 分别约 -34.8327 与 +34.8327 eV⁻¹，方向相反，且无分支切换。由于两条直接常数响应互相竞争，单看它们不能推导完整 DRC=-0.5；差异必须包含基线通量权重和受 I1/I2 约束的覆盖度重排。
- Ti–Fe：OOH DRC=+1.000000（两步长）；其 R2、R4 直接前向常数斜率与 Ti–Co 同为约 -/+34.8327 eV⁻¹，但总 DRC 符号相反。这说明单步 Arrhenius 斜率不是位点间 DRC 差异的充分解释；实际差异来自每个位点不同的基线状态/通量权重及全稳态覆盖度响应。R2 为 FS 端点控制的无显式 TS 步，R4 才是显式 TS 控制。
- Ti–Mo：OOH DRC=+0.000325/+0.000330，TS1 DRC约 +1；固定覆盖度 R2/R4 的 OOH 前向常数斜率相反。接近零的 OOH DRC与多步响应相消相容，但不能仅从两个直接斜率定量分解。TS1 DRC通过门控且该 TS 在扰动范围高于端点，表示当前模型 TOF 对 TS1 能量有强局部敏感性；它不等价于证明真实反应中存在唯一决速步。
- Ti–Ni：OOH DRC=-1.1764/-1.1765，TS1 DRC约 +1。R2 的 OOH 影响体现在逆向常数（`dln kr/dG≈+34.8327 eV⁻¹`），R4 影响正向常数（约 +34.8327 eV⁻¹）；OOH 同时处于不同反应状态，净 DRC 是全网络稳态响应。TS1 的强正敏感性与 Ti–Mo 一样属于模型局部敏感性，不单独建立真实 NEB 速控结论。

## 4. 主导 DRC 与覆盖度比是否具备普适性？

不具备。本分析仅按既有门控数据计算两幅度下的 `-X_dom/θ_dom`。如果主导态 DRC 两个 h 中任一个未通过，则比例为空而非补估。`3·X_TS1+2·X_TS2` 是探索性的加权比较，不是 CatMAP DRC 公式，也不是化学位点数；只有两个 TS 的扰动门控完整且有效 TS 位于端点之上时才保留。

## 5. 结果层级及执行边界

数值表描述现有 PROVISIONAL 八步候选输入下的原生 CatMAP 速率常数、净速率与归档 DRC；方向速率通过 mpmath 依照 CatMAP 解析的质量作用物种幂次重建，以规避官方方向通量 helper 转 Python float 的精度损失。三个位点方向通量与归档净速率逐步核对，能量扰动只调用官方 rate-constant API。所有这些都不等于 NEB 与独立态映射已经物理闭合。

本轮没有重跑稳态或 DRC；固定覆盖度数值检查次数有限。结果不可用于升级为正式 DFT 动力学结论或正式 SISSO 拟合。

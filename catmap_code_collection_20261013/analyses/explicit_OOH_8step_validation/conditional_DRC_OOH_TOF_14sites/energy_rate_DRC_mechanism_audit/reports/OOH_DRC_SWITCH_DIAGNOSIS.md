# OOH* 能量扰动—速率常数分支诊断

对每个位点固定既有合格覆盖度，仅将 CatMAP 参数向量中的 `OOH_s` 能量分别平移 ±0.005 eV；重新调用官方速率常数函数，不执行稳态重求、不重算 DRC。中心差分 `d ln k / dG_OOH` 表示直接速率常数响应，不是含覆盖度响应的完整 DRC。

## 位点结果

### Ti–Co

- OOH 能量改变势垒的步骤：R2, R4
- 控制分支切换：无 ±h 分支身份切换
- 速率常数导数摘要：R2 dlnkf/dG=-34.83, dlnkr/dG=0 eV⁻¹; R4 dlnkf/dG=34.83, dlnkr/dG=0 eV⁻¹
- 既有完整 OOH_s DRC（h=.005/.010）=-0.499737050172469636577402925267/-0.499734806101312551655491719872，门控 PASS_CONDITIONAL。
- 基线/±h 详细平衡最大 |ln(kf/kr)+ΔG/kBT|=6.96e-14/2.32e-14/2.32e-14。

## 与既有 DRC 的区别

完整 DRC 来自已归档的±能量扰动后受库存约束稳态重求；这里是固定覆盖度的 k 直接响应。只有二者方向/步骤相符时，才构成互补证据，不可把某一步的 `dln k/dG` 直接等同于 OOH* DRC。正逆常数比同时用每个 parsed reaction 的 `ΔG` 检查详细平衡，误差见 CSV。

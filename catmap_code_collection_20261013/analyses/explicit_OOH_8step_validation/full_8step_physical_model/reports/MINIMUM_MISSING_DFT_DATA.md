# 正式八步模型的最小缺失证据

研究者已确认所有本研究 Gibbs 输入完成热力学修正；本报告不把温度、频率或重新计算 Gibbs 列为缺失项。

## 阻止正式物理映射的最小数据

1. **共吸附状态几何和表面位点足迹**：NEB1/NEB2 的 IS、TS、FS 与对应独立吸附态的 POSCAR/CONTCAR（或等价结构文件），需能核验相同 slab/超胞、Ti–Co活性位、Ha旁观原子位置，以及 OOH、烯烃、环氧、O、Hb、OH 的结构对应。否则 `NEB1IS/TS/FS` 形式 `n_sites=3/3/4`、`NEB2IS/TS/FS` 形式 `3/3/2` 只能是片段占位假设。
2. **非NEB连接过程的独立 TS 或经研究者明确接受的条件性速率假设**：本候选中 H2O2吸附/活化、烯烃吸附、独立态↔完整 NEB1-IS/FS、环氧脱附、完整 NEB1-FS 到 NEB2-IS 的关联路径、NEB2-FS↔独立 Ha*+OH*、Ha*+OH*→H2O*、水脱附均没有各自独立的 DFT TS。CatMAP 的 `G_TS=max(G_IS,G_FS)` 可作为透明的端点势垒近似用于探索性条件计算，但不能视为 DFT 动力学参数。
3. **显式过渡态对应关系确认**：已有 NEB1/NEB2 Gibbs 数值可直接作为各自完整 NEB 状态的能量输入；但需结构匹配证据确认它们确实分别对应本网络定义的氧转移、Hb/O氢转移过程，并确认 Ha 旁观片段在连接边界连续。能量值本身不能证明几何/路径等价。

## 已有数据能够确定的量

- NEB1 与 NEB2 的 IS、TS、FS输入值及其有符号端点差和正逆显式TS势垒。
- 采用片段元素组成定义后，各候选状态的元素账目。
- 同一候选输入表推导出的连接端点 ΔG；例如 NEB1-FS→NEB2-IS+C6H12O(g) 为 `+0.811237 eV`，NEB2-FS→H2O* 为 `−0.601109 eV`。它们是热力学端点差，**不是**连接活化能。
- 12条候选反应的 CatMAP parser 计量、原子守恒、形式位点账目和两条库存零空间。

## 可执行边界

当前可复算地运行候选 parser、反应能量和 CatMAP 原生端点势垒计算；Ti–Co 零库存数值求解已实际尝试但未达到严格数值门槛，因此不输出新TOF。若研究者批准将缺 TS 过程按 CatMAP 端点近似作条件性动力学，并接受复合态几何足迹暂为粗粒化假设，可另行数值稳态求解；正式预测升级仍需上述结构/TS证据。

# 正式八步模型建立后的 14 位点执行流程

## 范围

14个既定目标：单 Ti 加 13 个 Ti–M（Ti–Co计入其中）；Ti–Nb作为额外候选单列，不混入目标集。现有旧批次 `multisite_batch_8step/MULTISITE_CALCULATION_STATUS.csv` 只代表旧九反应粗粒化候选的条件性结果，不能填充八步正式结果。

## 逐位点流程

1. 读取该位点自己的独立吸附态、NEB1/NEB2 IS/TS/FS Gibbs输入和来源哈希；不得套用 Ti–Co 形成能或端点差。
2. 对该位点分别执行状态定义与组成映射门控，结构/位点足迹不明时标记 `ENERGY_MAPPING_FLAGGED`，不把数值求解成功当作物理验证。
3. 用 CatMAP 0.3.1解析统一的显式 OOH 网络，导出位点加权化学计量矩阵与库存零空间；由网络单独推导该位点初始库存约束。
4. 仅对通过输入门控的位点运行 CatMAP 官方稳态速率方程。记录多精度/初猜、残差、非负覆盖度、加权位点和、库存误差、逐步正/逆/净通量及环氧产物 TOF。
5. 数值门控通过后，再在同一库存类和同一稳态分支做 NEB TS DRC。无独立 TS 的连接只报告明确标记的条件性敏感性，不与真实 NEB DRC 混用。
6. 只有同时通过物理映射和数值门控的数据进入 `VALIDATED_DATASET`；任何端点势垒近似结果单独保存为 `PROVISIONAL_ENDPOINT_MODEL`。未收敛、异常端点排序或输入不全均保留失败状态。
7. 14个位点全部完成后，才基于正式数据进行 OOH* 覆盖度–TOF–DRC 构效分析；Ti–Nb结果独立列示。

## 当前启动门槛

目前 Ti–Co 完整状态候选通过 parser、元素和形式位点检查，但复合态 footprint 未经结构验证，多个连接仍只可用 CatMAP 端点势垒近似；零库存稳态尝试也未过残差门槛。因此，现阶段不启动全位点八步求解或正式 DRC。优先补齐 `MINIMUM_MISSING_DFT_DATA.md` 中结构匹配/占位证据，并对未显式TS连接取得真实 TS 或明确批准限定为条件性计算。

## 结论

**目前不能把完整共吸附 NEB 直接等同于八步模型中的独立吸附态组合，也不能据此建立可用于正式稳态计算的闭合模型。**研究者已确认所有相关 Excel Gibbs 值均已作热修正，本报告接受该前提，不再把温度栏、频率或热修正列作阻碍。未解决的是：本机结构导出与 Excel 所指原始计算目录尚无可追溯的一一对应；NEB 全构型与独立态的几何/位点等价性未证实；而维持独立态和完整 NEB 端点间的连接势垒没有现成数据。

## 映射建议与当前限制

1. 保留八步前段 H₂O₂ 吸附/活化和显式稳定吸附态 OOH；不能把 OOH 并入隐含复合态。
2. NEB1、NEB2 的局部 IS–TS–FS 能量关系只能用于各自**完整共吸附构型路径内部**。建模时应把 Ha 旁观物纳入该完整状态的元素计量，不得从完整 NEB TS 能量中简单减去独立 Ha* 能量，也不得把 NEB 局部 TS−IS 势垒套到独立态端点上。
3. 若保留独立吸附态网络，应把完整 NEB IS/FS 视为不同的共吸附构型状态，除非原始几何能证明其与独立态组合相同。独立态组合进入 NEB1-IS、NEB1-FS 离开至产物态、NEB1-FS 经环氧物脱附连接 NEB2-IS、以及 NEB2-FS 连接后续水形成态，均需结构对应关系和/或各连接步骤的自由能、活化势垒。现有端点差值不能替代这些势垒。
4. CatMAP 中完整共吸附状态/TS 的 `composition` 与 `n_sites` 必须按可追溯几何定义。旧模型所有物种采用单有效位点的做法仅是粗粒化假设；本轮结构导出虽有元素计数，却不能确认真实几何占位数。故不生成可执行候选 `.mkm`，也不调用求解器。

建议的**状态拓扑（概念方案，非可运行 `.mkm`）**为：保留显式 OOH* 生成和烯烃吸附；将完整共吸附路径分别作为独立的构型状态序列处理：

```text
[Ha + OOH + C6H12]NEB1-IS  ⇌  [Ha + OOH + C6H12]NEB1-TS  →  [Ha + C6H12O + O + Hb]NEB1-FS
[Ha + Hb + O]NEB2-IS       ⇌  [Ha + Hb + O]NEB2-TS       →  [Ha + OH]NEB2-FS
```

方括号表示完整共吸附构型中的总表面状态（包含 Ha），不是把其中各吸附物假设为互不作用的独立能量之和。由独立稳定吸附态进入 NEB1-IS、NEB1-FS 经环氧物脱附连接 NEB2-IS、以及 NEB2-FS 接回水形成支路的边目前没有被同一结构证明，也没有对应连接 TS/势垒，因此不能写成带有臆定速率的 CatMAP elementary steps。两个 NEB 序列内部的已知 IS/TS/FS 能量可保留，但暂不足以连成完整稳态网络。

### 最少需要补齐的证据

- 将工作簿各 `calculation_path` 映射到原始计算目录，并取得 NEB1/NEB2 IS、TS、FS、对应 clean slab 及独立态计算实际使用的 CONTCAR/POSCAR（或 vasprun.xml 中结构）及计算目录清单；至少能核实 slab 原子、超胞、Ti–Co 相对位置、表面终止与 Ha 的位置/是否保留。
- 证明哪些 NEB 端点就是独立吸附态组合的同一微观状态；若不是同一状态，提供进入/离开共吸附态的连接势垒或真实连接路径 TS 数据。至少包括 NEB1 前驱独立态→NEB1-IS、NEB1-FS→NEB2-IS（包含环氧物脱附连接）、NEB2-FS→后续水形成态；也可通过有证据的状态同一性减少连接步，但不能假定零势垒。
- 给出共吸附复合物和过渡态在 CatMAP 格点中的物理 `n_sites`/占位映射；若继续用一个有效中心，需明确标为粗粒化假设而非由当前结构审计验证的几何事实。

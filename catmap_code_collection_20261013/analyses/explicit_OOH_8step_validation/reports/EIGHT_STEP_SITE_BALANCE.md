# 八步显式 OOH 模型：完整位点守恒与微量覆盖度展示筛选

## CatMAP 解析所得稳定物种与位点数

本机 CatMAP 0.3.1 对原始八步模型解析出 9 个稳定吸附物种：H₂O₂*、Ha*、Hb*、OOH*、C₆H₁₂*、C₆H₁₂O*、O*、OH*、H₂O*。这些稳定物种的 `n_sites` 全为 1。解析出的两个过渡态为 `OOH-C6H12_s` 和 `Hb-O_s`，不作为稳态覆盖度项。程序标识符映射与机器结果保存在 `../data/eight_step_parse_screen_summary.json`。

## 完整公式

```math
\begin{aligned}
1 ={}& \theta_* + \theta_{\mathrm{H_2O_2*}} + \theta_{\mathrm{Ha*}} + \theta_{\mathrm{Hb*}} + \theta_{\mathrm{OOH*}} \\
&+ \theta_{\mathrm{C_6H_{12}*}} + \theta_{\mathrm{C_6H_{12}O*}} + \theta_{\mathrm{O*}} + \theta_{\mathrm{OH*}} + \theta_{\mathrm{H_2O*}}.
\end{aligned}
```

若未来解析到 `n_sites` 不为 1 的稳定物种，必须改用 `θ_* + Σᵢ nᵢθᵢ=1`；不得把过渡态列入稳态覆盖度和。

## 零库存不变量

由 CatMAP 解析的 8 个反应及稳定吸附物种计量矩阵独立计算，秩为 7，左零空间维数为 2；两条核验式均满足 `I·S=0`：

```math
\begin{aligned}
I_1 &= \theta_{\mathrm{Ha*}} - \theta_{\mathrm{OOH*}} - \theta_{\mathrm{OH*}} - \theta_{\mathrm{O*}} = 0,\\
I_2 &= \theta_{\mathrm{Hb*}} - \theta_{\mathrm{O*}} = 0.
\end{aligned}
```

零库存 Ti–Co 根中 I₁=`2.263404106…×10⁻⁵⁷¹`，I₂=`0`；覆盖度加空位和为 1。该根是在求根坐标中施加库存约束的结果，不代表真实时间动力学可达性。

该单根可写作局部展示近似：

```math
\theta_* + \theta_{\mathrm{C_6H_{12}*}} + \theta_{\mathrm{OOH*}} \approx 1,

```

此式不重归一化、不用于反推空位，也不进入动力学。OOH* 虽低于阈值仍保留。它仅适用于该 Ti–Co provisional 根，不可推广到其他催化剂或工况。

# 显式 OOH 八步模型正式 TOF / DRC 就绪门控

## 结论

**当前未达到正式多催化剂 TOF、OOH*–TOF 构效或 DRC 分析条件。** 本轮完成官方解析、NEB 数值来源复核和现有 Ti–Co provisional 根覆盖度筛选，没有启动新的 CatMAP 稳态、TOF、DRC 或 13 位点批算。

## 最少补充工作

1. 补齐 NEB1/NEB2 IS/TS/FS 与对应 clean slab 的结构文件/原子组成/超胞和位点映射；证明 NEB 与单独吸附态能量能在同一物理 slab 参考下比较。
2. 找到 NEB2 IS/TS 及独立吸附态/slab 热修正的温度和振动修正记录。
3. 明确完整共吸附初态、TS、终态如何以原子与位点守恒映射进 CatMAP；若需稳定共吸附中间态或脱附/再吸附连接，提供真实 Gibbs 能或势垒，不能补零。
4. 物理能量门控通过后，再验证 Ti–Co 零库存根是否可由洁净空表面动力学到达；有限时间“变化很小”不足以证明稳态。
5. 只有在相同库存与稳态分支可复现的扰动流程建立后，才执行官方 DRC；然后扩展其他位点。

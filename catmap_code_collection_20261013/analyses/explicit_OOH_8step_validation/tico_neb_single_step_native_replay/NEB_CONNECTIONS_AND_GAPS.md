# Ti–Co 共吸附 NEB 与八步网络的最小衔接说明

## 验证边界

本次验证只证明 CatMAP 0.3.1 可以解析并计算这两条**孤立 NEB 路径**的能量差、正逆有效势垒及正逆速率常数。复合态使用明确化学组成的状态标签；三个路径态在测试模型中具有相同的形式 `n_sites=1`，这只是为 CatMAP 的反应解析和形式位点平衡设置的测试账本约定，**不是实际几何占位数的证据**。脚本没有求覆盖度、稳态、TOF 或 DRC。

## 有直接 NEB 支持的过程

| 路径 | IS → TS → FS 状态总组成 | ΔG = FS−IS (eV) | 正向势垒 TS−IS (eV) | 逆向势垒 TS−FS (eV) | 结果 |
|---|---|---:|---:|---:|---|
| NEB1 | C₆H₁₄O₂ → C₆H₁₄O₂ → C₆H₁₄O₂ | −0.239686 | 0.556344 | 0.796030 | CatMAP 0.3.1 原生复现 PASS |
| NEB2 | H₂O → H₂O → H₂O | −0.480580 | 0.225994 | 0.706574 | CatMAP 0.3.1 原生复现 PASS |

组成按用户指定/既有 NEB 状态定义计数：NEB1 包含旁观 Ha、OOH、C₆H₁₂（IS）及 Ha、C₆H₁₂O、O、Hb（FS）；NEB2 包含 Ha、Hb、O（IS）及 Ha、OH（FS）。同一路径各态的总化学组成守恒，因此官方 `verify()` 通过。测试并未把 Ha 当成无相互作用项扣除。

CatMAP 默认过渡态理论前因子 `kB*T/h` 下，官方 `SteadyStateSolver.get_rate_constants()` 得到：

| 路径 | k_forward (s⁻¹) | k_reverse (s⁻¹) | kf/kr | exp(−ΔG/kBT) |
|---|---:|---:|---:|---:|
| NEB1 | 2.66247979863219×10⁴ | 6.30084695729555 | 4225.59033202575 | 4225.59033202574 |
| NEB2 | 2.64671712881828×10⁹ | 1.42121093045841×10² | 18622971.9466384 | 18622971.9466384 |

`kf/kr` 与 `exp(−ΔG/kBT)` 的相对差在脚本保存的 `detailed_balance_relative_error` 中逐条记录；它反映官方生成函数常数表示路径的数值舍入，不是额外拟合参数。

## 与原始八步网络的连接：已知端点差，不等于已知动力学

以下端点差来自已有 `full_8step_physical_model/data/NEB_CONNECTION_ENERGY_MAP.csv`，只作来源明确的候选自由能差记录；不能据此指定连接速率或零势垒。

| 必要连接 | 已有端点 ΔG 候选 (eV) | 动力学信息状态 |
|---|---:|---|
| 独立 Ha* + OOH* + C₆H₁₂* → 完整 NEB1-IS | −2.663642 | 有候选端点差；连接 TS/正逆势垒缺失 |
| 完整 NEB1-IS → NEB1-FS | −0.239686 | 本次显式 NEB1 TS 与双向势垒已复现 |
| NEB1-FS → NEB2-IS + C₆H₁₂O(g) | +0.811237 | 有候选端点差；重排/产物释放动力学缺失 |
| NEB1-FS → 独立 Ha* + C₆H₁₂O* + O* + Hb* | +4.7039755 | 有候选端点差；解离/重排 TS 缺失 |
| 独立 Ha* + Hb* + O* → 完整 NEB2-IS | −3.1771455 | 有候选端点差；缔合/重排 TS 缺失 |
| 完整 NEB2-IS → NEB2-FS | −0.480580 | 本次显式 NEB2 TS 与双向势垒已复现 |
| NEB2-FS → 独立 Ha* + OH* | +1.5956585 | 有候选端点差；解缔/重排 TS 缺失 |
| NEB2-FS → H₂O* | −0.601109 | 有候选端点差；成水/重排 TS 缺失 |

因此，若要把完整 NEB 状态嵌入八步微观动力学，最少还要确定哪些独立吸附态与共吸附端点确属同一微观态；对非同一状态的连接，需要有物理依据的连接自由能以及至少能确定正逆速率的连接活化自由能/TS。已有端点差可约束正逆势垒之差（详细平衡），但不能单独给出二者的绝对值。不能把 NEB 局部 TS 直接移到原八步独立态端点上，因为既有审计显示独立态与完整 NEB 的反应自由能不一致。

# 吸附氢–过氧基均场处理评估

## 判定

当前 Ti–Co 候选把吸附氢片段 `Ha_s` 和 `OOH_s` 作为独立状态变量，并对它们在前驱连接反应中采用 CatMAP 平均场覆盖度乘积。候选的零库存约束为 `θ(Ha*)=θ(OOH*)`，不是独立的 Ha–OOH 配对状态。当前数值根不能验证真实局域相关性或配对动力学。

在基线根，`θ(Ha*)=θ(OOH*)≈2.2671358×10^-20`、`θ(C6H12*)≈0.9895345`，前驱连接正向通量为 `3.53063694×10^-27`。其 CatMAP 平均场因子为：

```math
r_{4,+}=k_{4,+}\,\theta_{\mathrm{Ha}}\theta_{\mathrm{OOH}}\theta_{\mathrm{C_6H_{12}}}
\underset{\theta_{\mathrm{Ha}}=\theta_{\mathrm{OOH}}}{=}
k_{4,+}\,\theta_{\mathrm{OOH}}^2\theta_{\mathrm{C_6H_{12}}}.
```

这平方依赖是“独立均场状态 + 本模型零库存约束”的数学结果，**不得解释成真实表面反应级数**。在本模型中，稀少的 Ha/OOH 覆盖度使三体平均场乘积极小，能解释候选根中前驱体形成通量为何极低；真实速率是否会因空间相关而明显增大，现有结果不能判定。

## 共吸附信息能说明什么

完整 NEB1 初态的组成和能量包含吸附氢旁观片段、过氧基及烯烃相关组分，因此它证明该组合状态在 NEB 路径端点中有一个候选整体能量。它**不是**孤立 Ha–OOH 配对态的能量，也不提供该配对态的位点占据数或从分离吸附物种形成它的独立势垒。整体前驱连接能不能拆成独立二元结合自由能，当前没有数据支持。

因此不能把 `θ(Ha*)θ(OOH*)` 直接替换为 `θ(OOH*)`，也不能只靠 NEB1 初态推出方案B的 CatMAP 速率式。方案B至少需要一个结构定义明确、组成与位点占据明确且与当前能量参考相容的 Ha–OOH 局域共吸附态 Gibbs 能，以及连接到/离开该状态的可用动力学参数；若该配对态即 NEB1 前驱整体态，则还必须明确它与烯烃共吸附及 NEB1 IS 的状态映射，避免重复计数。

## 研究解释边界

- **CONFIRMED（数值层）**：当前候选根中两覆盖度按约束相等；第4步正向通量满足 CatMAP 三因子均场形式，且几乎没有反向通量。
- **INFERRED（模型内）**：这条均场路径中的低覆盖度乘积是低通量的重要模型内原因；小幅提高第2或第4连接的假设势垒会进一步降低 TOF。
- **UNVERIFIED（物理层）**：Ha/OOH 是否随机独立、是否存在局域配对、实际位点几何、配对对势垒的作用，以及这是否导致现模型过度抑制活性。

完整方向速率见 `FORWARD_REVERSE_RATE_AUDIT.csv`；所有原始反应步骤仍保留于候选模型，没有通过低覆盖度删除物种或反应。

# 洁净表面到候选根的可达性诊断

## 已有官方积分证据

复用既有隔离运行 `candidate_tico_endpoint_model/clean_surface_reachability/`，没有重跑或修改 CatMAP ODE。调用 CatMAP 0.3.1 `SteadyStateSolver.get_ode_solution_coverage`，初值为空吸附层（所有吸附覆盖度为 0），条件为 333.15 K 和候选气相浓度。官方 `ODESolver` 源码调用 `mp.odefun`，默认积分步长 `dt=1e-15`，`tol=1e-1`、degree=2；SteadyStateSolver 默认最多 300 次迭代。

300 步终点为约 `3.00×10^-13`（按该实现时间单位），残差仍为 `8.46269456×10^11`，抛出 `Out of iterations`。积分没有展示从洁净表面接近稳态；残差如此大也说明本次轨迹不能当作趋近证据。但该失败**不能证明**无可达稳态，原因可能包含严重刚性、时间尺度/速率单位与积分步长不匹配、空覆盖边界初值处理，以及极低通量状态的积分要求；本轮没有改动官方迭代上限或时间参数去追求表面成功。

## 库存类与候选模型边界

项目原始八步机理的已审计计量矩阵有两个库存不变量：

```math
I_1=\theta_{\mathrm{Ha}}-\theta_{\mathrm{OOH}}-\theta_{\mathrm{OH}}-\theta_{\mathrm O},\qquad
I_2=\theta_{\mathrm{Hb}}-\theta_{\mathrm O}.
```

原始八步模型从洁净表面出发需要 `I1=I2=0`。本轮所复用的 Ti–Co provisional 候选网络没有把 O、OH、Hb 作为各自独立稳定覆盖度变量；数值求解只在其约化变量上精确施加 `θ(Ha*)=θ(OOH*)`。因此，它只能证明**约化候选模型的数值根**，不能声称满足/代表原始八步网络的完整库存类，更不能作为完整网络由洁净表面可达的证据。

## 结论及下一步所需证据

- **CONFIRMED**：约化候选的 220 位求根在给定零库存约束下可以达到高精度稳态；CatMAP 官方空表面 ODE 在当前 300 步设定下没有达到该根。
- **UNVERIFIED**：此根是否能由实验洁净表面通过完整八步动力学轨迹到达；完整原子/库存映射是否与候选约化变量一致。
- 后续若要给出可达性结论，需先有可验证的完整八步能量/状态连接映射，并在固定 `I1=I2=0` 下选择经尺度分析的刚性积分/轨迹验证；不得把 Newton 求根初猜当作物理初始条件。

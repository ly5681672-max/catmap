# Ti–Co provisional 候选：机制核查摘要

**对象与边界：** CatMAP 0.3.1，既有 Ti–Co 九条基元候选（八个化学阶段），333.15 K；气相浓度输入为 C6H12 1.0、H2O2 0.185、H2O 0.815、C6H12O 1e-20。沿用既有候选能量和 1 个有效位点粗粒化，不是完整表面几何已验证的正式模型。未改原始输入；未计算其他催化剂；未开展六步研究、条件搜索或 Git 操作。

## 1. 极低 TOF 根因（候选模型内）

严格基线重放的产物 TOF 为 `3.5306369400998473×10^-27`。主要覆盖度：烯烃吸附态 `0.9895345223`，空位 `0.01046547773`，吸附 H2O2 `9.97395×10^-18`，吸附水 `1.04975×10^-18`，Ha 与 OOH 均 `2.26714×10^-20`；完整 NEB1/NEB2 中间状态覆盖度约 `10^-28` 至 `10^-35`。

用高精度正逆通量而非双精度相减检查：

- 第1步过氧化氢吸附正/逆 gross rates 均约 `6.923635×10^-5`，相减后的净值约 `3.53063694×10^-27`。该步骤接近平衡，不能因净通量小就把它单独判为速率决定步骤。
- 第2步 H2O2 活化正向约 `7.09861447×10^-27`，逆向约 `3.56797753×10^-27`，净通量为 `3.53063694×10^-27`。第2步连接的假设性正向增垒敏感性 `X≈0.519/0.541`（δ .005/.010 eV），提示该候选对这段输入假设敏感。
- 第4步进入完整 NEB1 初态，正向通量 `3.53063694×10^-27`，逆向仅 `1.38039×10^-62`，其净通量和产物 TOF 在数值输出精度下一致。它直接包含 `θ(Ha)θ(OOH)θ(烯烃)`，而 Ha/OOH 极低且被强制相等；这是模型结构下抑制通量的直接数学机制。对这段缺失 TS 的连接加 δ 情景给出 `X≈0.524/0.546`，但它完全是条件性假设，非 DFT DRC。
- 第5/7步显式 NEB 的正、逆 gross rates 较大并强烈抵消，净通量仍闭合到 TOF；其条件性 NEB TS DRC 分别约 `3.34×10^-31`（NEB1）和 `3.36×10^-36`（NEB2），在此候选稳态中实际上近零。

因此低 TOF 不是单一“NEB1 或 NEB2 能垒很高”的结果。该候选主要受低通量前体生成/连接条件与均场乘积共同约束；显式 NEB TS 本身在局部 ±meV 扰动中几乎不控制输出。是否为真实催化剂物理，仍被共吸附态映射、位点粗粒化及空表面可达性限制。

## 2. 条件性 DRC 结论

NEB1/NEB2 TS 扰动均维持同一零库存约束、储库和覆盖度分支，且详细平衡比值保持不变；两种差分幅度给出的近零值相差约 1.5%。七条无显式 TS 连接的 δ 敏感性中，第2（保持原单向语义）和第4显著，其他步骤约为零。缺 TS 连接敏感性不能升级成 DFT DRC，也不能凭 `X≈0.5` 宣称唯一决速步骤。

## 3. Ha/OOH 均场与洁净表面

完整 NEB1 初态含旁观吸附氢是已有状态级证据，但没有独立 Ha–OOH 配对态的能量/占位/连接势垒，不能建成方案B并与方案A作物理对照。官方空表面 ODE 在 300 次、约 `3×10^-13` 积分时间后失败，残差仍 `8.46×10^11`；不能证明不可达，也不能把求根种子当物理初值。约化候选未表示完整八步网络的全部 Hb/O/OH 状态，故不证明原完整模型两个库存不变量。

# Ti–Zr 有界数值恢复结果

- 重放对象：Ti–Zr 原始八步 CatMAP 0.3.1 输入。
- 输入：温度 333.15 K、`pressure_mode='static'`、储库浓度数值、原始 Gibbs/NEB、反应网络及零库存约束均保持不变；输入 SHA-256 记录于 `../data/TIZR_FINAL_NUMERICAL_GATE.json`。
- 过程：先复现既有 385 dps 重放路径，在旧 `1e-50` 缩放残差处（5 次迭代）保存早停状态；仅从该状态进行一次同精度有界抛光，目标缩放残差 `1e-100`，最多 100 次，实际 1 次收敛。
- 抛光结果：缩放残差 `1.70935e-111`；最大绝对独立物种残差 `1.66787e-119`；位点占据和 `1`；`I1=6.59e-408`、`I2=0`；8 步净通量最大相对偏差 `6.56e-49`；各吸附态非负。
- TOF：`2.5428806411947284348342241650334571989768e-71 s^-1`；相对归档覆盖度重新评估值差 `1.29e-17`，远小于保持不变的 5 ppm 门槛。
- 旧停止点 TOF：`2.5442868377664985656134834907947909351988e-71 s^-1`；相对归档快照差 `5.52994e-4`（约 553 ppm），并且该根最大残差大于 TOF 约 16 个数量级，故不能作为已通过稳态门控的根。
- 不做第三次恢复，不提高到更高精度，不更改旧门控，不回写旧结果。新数值状态为 `NUMERIC_PASS / PROVISIONAL`；旧记录仍保留 `NUMERIC_PARTIAL`。

本轮方向速率的 mpmath 表达式来自 CatMAP 官方 `rate_equation_term()`，CatMAP 净速率来自 `get_rxn_rates()`。`get_directional_rates()` 返回方向速率时经 `get_elem_ec()` 的 Python `float` 转换，因此不用于超小净速率相减。

# Ti–Zr 跨精度差异根因诊断

## 结论

历史重放的约 553 ppm TOF 差异已在不改变模型、能量、温度、储库或库存约束的条件下复现并消除。直接原因是跨精度重放沿用了 `scaled_residual < 1e-50` 的早停条件：5 次迭代后停止时，最大独立物种绝对稳态残差为 `2.60146e-55`，而产物循环通量约 `2.54288e-71 s^-1`，残差约大 16 个数量级。再从该停止点以相同 385 位精度进行一次有界 Newton 抛光（100 次上限，实际 1 次），得到 `1.70935e-111` 的缩放残差和 `1.66787e-119` 的最大绝对物种残差；TOF 与归档覆盖度快照重新评估值的相对差为 `1.29e-17`，通过原有 5 ppm 复现目标。

因此，旧 `NUMERIC_PARTIAL` 不是已证明的另一稳态分支，而是早停容差不适合当前极低通量的残差尺度。数值恢复状态可记为 `NUMERIC_PASS`，科研结果仍为 `PROVISIONAL`，不代表八步物理映射已获正式验证。

### 正逆通量与精度

最终采用 CatMAP 官方 `rate_equation_term()` 生成质量作用表达式，并以 mpmath 精度求方向速率；净速率仍直接取 CatMAP `get_rxn_rates()`，并核对 `forward-reverse` 恒等式。没有用 `get_directional_rates()` 的 Python 浮点结果做净速率相减。该 API 经源码检查会在 `get_elem_ec()` 中对速率常数、覆盖度和压力调用 `float(...)`；对约 `1e-71` 的净值，相比约 `1e-10` 的正逆分量，双精度舍入远不足以保留差值。

有界抛光解中，8 步净通量相对产物 TOF 的最大偏差为 `6.56e-49`；最大绝对物种残差 `1.67e-119`。逐物种局部归一化残差最大约 `1.71e-111`。完整方向速率、相消因子、身份误差和每个根的残差见 `../data/TIZR_FORWARD_REVERSE_FLUX.csv` 与 `../data/TIZR_ROOT_COMPARISON.csv`。

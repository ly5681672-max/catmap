# CatMAP 八步模型统一数值验收建议

## 原则

把求解器停止量、稳态方程质量、守恒、跨精度重复性和科研物理有效性分开。以下门槛只评价**数值质量**；即使 `NUMERIC_PASS` 也不能将 PROVISIONAL 的能量映射升级为正式 DFT 动力学结论。

## 建议的统一验收

### A. 稳态方程

对每个独立表面物种 (i)，用 CatMAP 实际计量矩阵和正逆通量定义：

\[
F_i=\sum_j\nu_{ij}(r_j^+-r_j^-),\qquad
J_{i,\mathrm{gross}}=\sum_j|\nu_{ij}|(r_j^++r_j^-).
\]

逐物种报告 `|F_i|`、`J_i,gross` 和 `|F_i|/J_i,gross`；`J_i,gross=0` 时标为不可定义/需诊断，不能加任意小分母。建议 `max_i |F_i|/J_i,gross ≤ 1e-12` 作为统一相对稳态验收线：它要求至少12位的局部通量平衡，比通常报告的6位有效数字留出6位余量；门槛作用在正确的局部正逆通量尺度上，不是为了让旧结果通过而放宽。另保留 `max |F_i|` 作为带单位诊断值，不对所有速率量级施加固定 `1e-45` 限值。

CatMAP 自定义 scaled residual 可用于迭代停止和复现日志，但不再把 `<1e-50` 当作必须达到的科学验收阈值。应以逐物种局部归一化残差作物理解读，同时记录所用算术精度和求解器停止状态。

### B. 守恒与可行域

- 覆盖度：非负（数值容差按所用 MP 精度和导出舍入设定），并满足 CatMAP 位点占据约束。
- 当前零库存参数化下：检查 I1、I2 的解析映射确实成立；导出后以写出有效位数对应的舍入误差作独立检查。若 CSV/JSON 有 (p) 位有效数字，建议舍入容差不小于其最后一位量级，且不超过 `10^(-p+10)`；本次约80位存档对应量级约 `1e-70`。这只是本批序列化检查，不是普适物理阈值。
- 不要求 `1e-300` 库存误差；若参数化不能保证不变量，应对真实状态向量独立计算，并按实际精度给容差。

### C. 跨精度/重复求解

两次计算各自先通过 A、B，再比较：

- `|Δlog10(TOF)| ≤ 2.17147e-6` decades，对应相对 TOF 差不超过约 `5e-6`（约6位有效数字）。
- 主要覆盖物种（如覆盖度 ≥`1e-8`）与核心 OOH 覆盖度分别比较。使用 `|Δθ|/max(|θ_1|,|θ_2|)`；建议上限 `1e-4`（4位相对一致性）。当两值均低于序列化/算术分辨率时，报告绝对误差界和 `UNRESOLVED_BELOW_RESOLUTION`，不计算误导性相对误差。
- 同时核验零库存类别、稳态分支判据和 CatMAP 产物 TOF 与高精度净反应速率重建一致。

跨精度重现不是“改变几位精度后数值看起来相似”即可通过；两次都必须先通过方程、守恒和通量检查。

### D. 产物通量与数值消去

采用 CatMAP 高精度 net reaction rate 计算气相产物 TOF，并根据气相化学计量重建独立核对。对方向速率做正逆相减前，必须确认接口不丢精度。本机 CatMAP 0.3.1 `get_directional_rates()` 返回 Python float（源码路径见 audit），因此其结果不应用于极低净 TOF 的消去误差判定。方向分量条件数如需报告，必须另以任意精度求得，不可从 float 接口推断。

反应通量不要求所有八个基元反应净速率彼此相等；验收对象是各独立表面物种满足 `S·r=0`，以及气相产物 TOF 与相应净反应计量一致。对存在循环/旁路的网络，强制所有基元通量相等并不正确。

## 本批适用的实际结果

以以上逻辑复核，已存根的11个催化剂中10个满足建议的数值标准；Ti–Zr因 `Δlog10(TOF)=2.4009566e-4` decades 未达到统一6位重现目标，故仅为 `NUMERIC_PARTIAL`。Ti、Ti–Hf 原来因全局净速率归一化而被排除的根可判为数值通过。Ti–Mo、Ti–W、Ti–Ta 仍无通过根，保持失败/未求得，不由新门槛自动变为通过。

对下一批所有催化剂采用相同的 A–D 规则和相同阈值；阈值在计算前固定，不按位点调整。求解器精度可自适应增加，但不能降低方程或重复性验收要求。

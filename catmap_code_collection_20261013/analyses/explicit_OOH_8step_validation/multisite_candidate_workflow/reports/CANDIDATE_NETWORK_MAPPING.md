# 显式 OOH 八步主线与条件性复合 NEB 候选网络映射

## 结论状态

本文件记录的是用于检验多催化剂工作流的 `PROVISIONAL` 条件性候选，不是原始八步网络的等价替代，也不是正式 TOF 模型。独立 Ha/OOH 与完整共吸附 NEB 状态之间的粗粒化没有被结构数据证明；完整 NEB 状态采用 `n_sites=1` 是单有效中心假设，不等同于真实几何占位。

## 状态映射

| 条件性候选网络状态 | 所映射阶段 | 数据来源/边界 |
|---|---|---|
| `H2O2*`, `Ha*`, `OOH*`, `C6H12*` | 原始八步第1–3阶段的独立稳定吸附态 | 历史形成能表；仅以程序标识保留，结构等价性不因名称自动成立 |
| `NEB1IS*`, `NEB1TS*`, `NEB1FS*` | 第4阶段完整 NEB1 共吸附 IS/TS/FS | 各位点 `DFT_TS_relative.csv` 总 Gibbs，按同位点洁净 slab 与既有元素参考换算 |
| `NEB2IS*`, `NEB2TS*`, `NEB2FS*` | 第6阶段完整 NEB2 共吸附 IS/TS/FS | 同上；保留原始有符号 TS−IS/FS，不作零势垒截断 |
| `H2O*` | 第7–8阶段吸附水/水脱附 | 独立吸附态形成能 |

条件性候选将原八步的第4阶段表达为“独立吸附态汇合至 NEB1IS、显式 NEB1TS、NEB1FS”；第6阶段 NEB2FS 连接至独立 `H2O*`。第5阶段产物释放连接写为 NEB1FS → NEB2IS + `C6H12O_g`。这些连接没有独立 DFT TS，CatMAP 端点势垒仅是探索性近似。

## 条件性候选九步及化学计量

1. `* + H2O2_g <-> H2O2*`
2. `H2O2* + * -> Ha* + OOH*`（单向，限制可逆稳态/DRC解释）
3. `* + C6H12_g <-> C6H12*`
4. `Ha* + OOH* + C6H12* <-> NEB1IS* + 2*`
5. `NEB1IS* <-> NEB1TS* -> NEB1FS*`
6. `NEB1FS* <-> NEB2IS* + C6H12O_g`
7. `NEB2IS* <-> NEB2TS* -> NEB2FS*`
8. `NEB2FS* <-> H2O*`
9. `H2O* <-> H2O_g + *`

在此候选的独立表面物种列表中，化学计量矩阵的零库存左零空间包含 `theta(Ha*) - theta(OOH*) = 0`。这是本候选网络自身的约束，不是原始八步的库存不变量。原始八步有 `I1=theta(Ha*)-theta(OOH*)-theta(OH*)-theta(O*)` 与 `I2=theta(Hb*)-theta(O*)`；删去 Hb/O/OH 并把完整 NEB 状态改为复合占位后，没有证据证明该降维是严格动力学粗粒化。

候选模型假设所有吸附物种及 NEB 复合态均占一个有效位点，因而代数位点平衡为

`theta_* + sum(theta_i for all candidate stable adsorbates) = 1`.

CatMAP 按此假设进行质量作用计算。它仅证明该输入的形式位点守恒，不能证明 NEB 共吸附结构在真实表面只占一个位点。

## 适用边界

- 真实 NEB TS 的有符号端点差与 CatMAP 端点处理必须分别报告；负 TS−IS 不得重写为零或正势垒。
- 连接反应的端点自由能差不是活化能；缺失连接 TS 的输出只能标 `PROVISIONAL`。
- `Ha* = OOH*` 只由当前候选网络守恒关系推导；不能迁移至原八步或其他候选网络。
- 不以条件性计算结果拟合正式 OOH–TOF 关系，也不将 Ti–Co 数值套用到其他表面。

# 原始八步显式 OOH 模型：静态储库稳态与条件性 DRC 批次报告

## 结论与可信度

本批在原始八步 `.mkm` 和原始 Gibbs 表不变的条件下，调用本机 CatMAP 0.3.1 `ReactionModel`、`ThermodynamicScaler`、`SteadyStateSolver`，按原模型两个库存不变量的零库存类计算。14 个目标位点中，11 个找到零库存数值根；其中 8 个通过脚本既有跨精度验收，3 个根虽通过高精度主求解但未通过跨精度门槛；另 3 个没有可接受根。结果一律是 `PROVISIONAL`：CatMAP 数值稳态成功不能解决 NEB 共吸附态与独立态端点的物理映射问题，也不能证明由洁净表面启动的动力学可达性。

## 数值门控、通量与 DRC

- 每个接受根均满足输出的 `I1≈0`、`I2=0` 和位点总和 `=1`；收敛根的最大相对独立稳态残差见汇总 CSV。
- 11 个接受根都计算了 CatMAP 原生速率表达式下的净通量；每位点的 `cycle_max_relative_error`、表面/气相化学计量重建误差均保存在 JSON。
- 严格跨精度门槛通过 8/14（含 Ti–Co）；未通过但有根 3 个（Ti、Ti–Hf、Ti–Zr）；未找到根 3 个（Ti–Mo、Ti–W、Ti–Ta）。跨精度未通过不作为严格合格结果。
- 对接受的根执行同库存中心差分条件性 DRC，步长 `0.005/0.010 eV`。Ti–Co DRC 详见 `tico/conditional_drc.csv`；所有其余位点 DRC 在对应位点目录。它们是基于 CatMAP 原生速率/稳态函数、在零库存约束流形上重新求解所得的 `PROVISIONAL_SAME_INVENTORY_DRC`，不是未经约束的 CatMAP stock `get_rate_control()` 输出，也不是物理映射闭合后的正式 DRC。
- 原始八步模型第 2 步的 `->` 在 CatMAP 0.3.1 仍有正、逆方向速率常数实现；因此模型求解语义按 CatMAP 实际可逆速率处理，不应称为严格单向动力学。
- 静态 Ti–Co 重放与既有浓度探针在 CatMAP 实际接收的气体向量相同，所得覆盖度和 TOF 完全一致；这只验证该数值输入向量下的重放一致性，不重新定义储库单位。

## NEB 物理边界

CatMAP 0.3.1 在当前独立吸附态映射下以 `max(G_IS,G_FS,G_TS)` 构造有效过渡态能量。Ti–Co 第 4 步模型端点反应自由能为 `+1.8006475 eV`，有效正/逆势垒为 `+1.8006475/0 eV`；第 6 步端点反应自由能 `−2.0620670 eV`，有效正/逆势垒为 `+0.225994/+2.288061 eV`。这些是当前 CatMAP 网络实际势垒，不等于完整共吸附 NEB 路径势垒；完整 NEB 与独立态端点物理映射仍 `UNVERIFIED`。所以跨位点 TOF、覆盖度及 DRC 仅用于当前候选网络的条件性数值对照，禁止作为正式 DFT 动力学排序或 SISSO 数据。

## 失败位点解释

- Ti–Mo、Ti–Ta：已进入多初值数值求根但无根通过验收；见 `constrained_solver_attempts.json`，其中包括 Jacobian 数值奇异、空位趋近边界/残差未达门槛。不能据此宣称物理上不存在稳态。
- Ti–W：初始运行时历史根投影不在正零库存图内；随后仅改用均匀 logit 初值重试，所有尝试落在近零空位边界/未通过门槛。物理输入未变。
- Ti–Zr：历史根投影同样无效；均匀初值重试找到高精度根，但独立微扰重放 `Δlog10TOF≈2.40e-4`，未过既有跨精度门槛，故列为待确认而不是严格通过。

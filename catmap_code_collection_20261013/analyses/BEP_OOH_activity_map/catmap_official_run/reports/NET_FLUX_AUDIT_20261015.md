# BEP–OOH CatMAP网格净通量一致性核验（2026-10-15）

**测试方式：** 直接复核GitHub归档的`data/grid_61x61.csv`和`data/grid_61x61_net_rates.csv`，不重新运行DFT、CatMAP或任何3721节点求解。

## 本次实际测试结果

- 网格/净速率均为 **3721条**；原始CatMAP状态表记录3721条CONVERGED。
- 注意**顺序差异**：`grid_61x61.csv`按`(grid_j, grid_i)`坐标排序；净速率CSV保留逐行折返的**蛇形求解顺序**。按脚本源码中的蛇形规则配对后，独立复算的6步净通量相对差异与原`flux_spread_relative`字段最大偏差仅 1.876e-16。因此先前直接按行号合并会误配。
- `flux_spread_relative > 0.01`：**127个**；`>0.10`：**64个**；`>0.50`：**28个**。
- **64个偏差＞10%的节点全部满足log10TOF＜−30**，属于极低活性区域。
- `log10TOF≥−30`的2989个节点：最大相对净通量差异为 1.814884e-6，没有相对偏差大于1%的节点。
- 全部节点导出的最大稳态残差：8.422906e-71，在归档求解器绝对残差容差1e−70内。**绝对稳态残差满足容差并不自动保证所有微小净通量的相对一致性。**

## 最小成本判断

1. 不建议现在重跑61×61网格；高活性区不存在同级别净通量异常，原报告中的边界高TOF位置暂未被这一检查推翻。
2. 建议论文或正式PPT将`log10TOF＜−30`区间标注为**极低通量、相对净通量未全部通过一致性检查**，不要将这些节点的精确TOF末位数字用于定量机制结论。
3. 上述分布强烈提示**极低通量下绝对残差与相对通量精度口径不一致**，但尚未在本机CatMAP 0.3.1中重放异常节点，**不能宣称已查明数值根因或已修复求解器**。
4. 如未来必须彻底核验，仅定点复算(i=0,j=0)和(i=0,j=30)两个异常节点，比较`solver.get_residual`、`rate_map`、`directional_rates_map`、`coverage_map`；优先核对CatMAP官方源码，不应修改稳态方程、BEP参数或大规模重跑。

**记录说明：** 原净速率CSV没有`grid_i/grid_j`列，不能按单独行自行识别节点；本核验遵循已归档`run_bep_ooh_activity_map.py`中`run_grid`蛇形循环和`flatten_rates(node_rows)`写入顺序。正式科研输出建议在未来新导出时给覆盖度/净速率表附加坐标键，以防后续误配。本次不改旧数据。

# 执行及验收顺序

1. 快照化13个严格 `.mkm`/`energies.txt`、BEP原始13位点表和归档收敛TOF表；记录来源SHA256；验证行键、温度、储库、机理、容差及能量映射。
2. 只用13个原始位点重拟合精确中心化四参数BEP，核对R²；在隔离输入中对13个位点各自调用CatMAP官方稳态求解器，比较归档TOF与覆盖度/残差/位点和。
3. 基线通过后，执行全13点拟合TS1替换和逐点留一（每折只用其余12点重新估计中心及系数）TS1替换；其余能量不变，各工况独立调用CatMAP。
4. 用历史BEP网格文件的精确坐标范围，执行5×5、15×15、61×61；每个节点有独立能量输入与CatMAP模型运行。官方MinResidMapper初值延续相邻收敛节点；求解失败时沿相邻节点坐标做有界二分，仍失败则保留FAILED与日志。只按完整输入哈希复用已验收结果。
5. 汇总所有节点、验证完整笛卡尔网格/稳态残差/覆盖度非负和位点守恒，生成PNG/PDF/SVG及报告；区分物理TS标记、端点控制、基准数据与条件背景。
6. 检查仅本任务新增文件的差异、SHA与测试；保留既有科研文件及用户工作。仅明确暂存本子目录中受控源码、输入快照、汇总、图件、README和报告，提交并普通push `main`；若远端冲突或出现未授权修改则停止，不强推。

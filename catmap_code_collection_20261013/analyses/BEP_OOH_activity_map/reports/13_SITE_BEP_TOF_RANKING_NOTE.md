# 13位点BEP-TS1替代后的探索性TOF对比（与二维条件活性图配套）

使用完整13位点的严格归档六步反应态能量，**仅以4参数OOH*扩展BEP预测的 `G(TS1*)-G(Rpair*)` 替换各位点原TS1**，其余中间体能量、TS2及浓度条件不变。采用独立环式解析稳态求解器复现基准TOF，最大log10TOF偏差=1.8452e-6，不代表已执行官方CatMAP 0.3.1的新求解。

- 模型R²=0.886665（用这同一批13位点拟合），因此下述排序是**训练内情景/能量敏感性测试，不是独立预测结果**。
- 原基准：单Ti最高（TOF 7.69 s−1），Ti–Co次之（3.71 s−1）。
- 仅替换TS1为BEP预测值：Ti–Co约 3.6774 s−1，单Ti约 0.9253 s−1；Ti–Co排序暂变第一。这一排名变化**来自对原DFT TS能量施加样本内拟合误差**，不能被解释为“发现双核更强”。它恰恰说明需要检查反应网络结果对过渡态能量预测误差的敏感性。
- TS1预测相对于Rpair为负的位点：Ti-Fe、Ti-W、Ti-Ta，使用端点夹断，不能称为独立NEB真实活化能。

要形成可投稿的BEP–CatMAP结果，需要在本机CatMAP 0.3.1对13个位点新输入逐点重求、做严格参考一致性检查，并且考虑留一模型预测、真实DFT过渡态的不确定性和第三步端点近似。图件仅作汇报“模型修正敏感性”而非确证双核优势。

# TS1_s + TS2_s 火山图分析

本分析按项目归档约定分为：`data/` 输入快照，`figures/` 图，`origin_exports/` 网格和点数据，`scripts/` 复现脚本，`reports/` 结果说明。CatMAP 0.3.1 模型与运行档案另存于归档根下 `catmap_official_run/TS1_TS2_descriptor_grid/`。

本包为新增归档，不覆盖原始输入、既有结果或历史目录。复制前输入 SHA256 与原归档一致。完整文件摘要清单在 `reports/SHA256SUMS.csv`。运行脚本有 C 盘绝对路径依赖，归档后未经路径迁移验证，不声称可直接运行。

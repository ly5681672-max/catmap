## 1. 真实物理路径（已由研究者确认）

- **NEB1 = 八步第4步（氧转移）**：`Ha* + OOH* + C6H12* (+ 空位) -> [NEB1_TS, Ha始终存在] -> Ha* + C6H12O* + O* + Hb*`。末态**没有 H2O**。
- **NEB2 = 八步第6步（H/O 反应）**：`Ha* + Hb* + O* -> [NEB2_TS, Ha始终存在] -> Ha* + OH* (+ 空位)`。末态**没有 H2O**。
- `catmap数据集!BN43`（OOH-C6H12）和 `BN47`（Hb-O）是**不含完整 Ha 环境的独立候选结构**，不可替代完整 NEB 的 TS。
- 完整 NEB 的**原子组成**：NEB1 为 `C6H14O2`，NEB2 为 `H2O`（包括旁观 Ha）。反应前后原子守恒；**真实物理位点占据数尚需原始结构验证**。
- 按当前八步表达式的**形式位点**，将旁观 Ha 加回去：NEB1 左右各 **4 个形式位置**（初态额外一个空位），NEB2 左右各 **3 个形式位置**（末态额外一个空位）。形式守恒 **不等于** 分子筛 Ti–O–Co 局域结构上具有4/3个独立反应位点。

## 2. 能量零点及可追溯来源

- 气相、表面和吸附态数据：`lyq_alkene_epoxidation/2-creating_microkinetic_model/{DFT_TS_relative.csv,DFT_adsorption.csv,energies_dft_neb.txt}`。
- **唯一的原始工作簿**：`lyq_alkene_epoxidation/己烯环氧化.xlsx`（二进制原文件保留）。
- `catmap数据集`：Ti–Co 的 Gibbs 能列 **BN**；`BN51` 为洁净 slab；`BN8, BN12, BN16, BN20, BN24, BN29, BN34` 分别对应 Ha、Hb、OOH、C6H12、C6H12O、O、OH。
- `吉布斯自由能汇总`：原始 NEB1 IS/TS/FS 为 Ti–Co 的 **12/16/20 行**；NEB2 为 **24/28/32 行**。原始 XLSX 的**实际 G 列字母尚未通过连接器读取**，不能编造；附脚本会从表头确定列字母并逐单元格检查。
- 采用原有 `convert_dft_to_catmap.py` 的**原子参考**：`mu_C=-9.28, mu_H=-1.11, mu_O=-4.37 eV`；`G_slab(BN51)=-868.516201 eV`。因此 `mu_ref(C6H14O2)=-79.960000 eV`、`mu_ref(H2O)=-6.590000 eV`。
- 条件性对齐规则：`G_form_NE B = G_full_NE B - G_slab - Σ n_i mu_i`；独立态 `G_form_ind = Σ G_form_species`；`δ_coads = G_form_NE B - G_form_ind`。**必须再核验 NEB 超胞、slab、相同温度和频率校正**，才能把 δ 归因为共吸附效应。

**证明两套参考不等价，而不是证明 Excel 错误。** 仅在 IS/TS/FS 都是原始 NEB 同一组结构时，正逆向势垒和反应能才构成一套自洽的反应路径。当前 `energies_dft_neb.txt` 中 `OOH-C6H12=-28.3789315`、`Hb-O=0.043544` 是把真实 NEB TS−IS 差映射到**独立态初态**后得到的值，**不能据此认定八步局部势垒在真实共吸附环境中相同**。

## 5. 目前结论边界、下一步

1. **已证实**：原始 NEB1、NEB2 各自的 TS−IS、FS−IS 数值；独立形成能之和与原始 NEB 反应自由能不同；形式原子、位点数守恒。
2. **条件性推断**：表中标作 `NEB − 独立态` 的数值，是基于**NEB 与单物种吸附计算的 slab 和能量参考相同**这一假设计算的能量偏移，不能未经证据称为共吸附作用能。
3. **仍需原始结构证据**：两条 NEB 的 NEB-IS/TS/FS 是否与单独吸附计算具有相同 Ti–Co slab/超胞、势能面、热修正、位点占据；是否存在某个局部多步子路径。
4. **不能现在做的事**：把 +2.0403335、−1.5814870 直接加到某个 TS；无依据地把独立态与共吸附态连接速率设为无能垒；改写原始八步输入或宣布修正后的 TOF。
5. **科学上的下一步**：优先复核 NEB1/2 原始几何和参考是否同源；若同源，再以完整 NEB IS/TS/FS 构造共吸附态连接的最小物理模型，保留显式 OOH* 并审查 CatMAP 的真实可用位点定义；只有取得连接态势垒/合理近似后才重新求稳态。
6. **源 Excel 再核验**：运行 `scripts/rebuild_tico_audit.py` 会读取工作簿并动态定位原始 G 列，核验全部源数值并重生成 CSV。若源 XLSX 不可读，输出会明确标记验证未完成，不能冒充已做源单元格复核。

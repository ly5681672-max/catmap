## 形成能与吸附能定义

对本文约定的原子参考，数值形式为：

`G_form(C*) = G(slab+C*) - G(clean slab) - μC`。

若 `μC` 选为孤立原子能量，这也可称为相对原子 C 的吸附能（需注明符号约定）；若使用石墨/其他碳相化学势，则数值和物理含义不同。它不是仅凭元素参考常数就能得到的值。

## 尚需的最小原始数据

- 每个目标 Ti–M 位点一个真实的单原子 C* 吸附结构及其计算输出/总能（本研究共同位点为 13 个）；结构必须有明确的吸附位点/构型标识。
- 每个位点可一一对应、同晶胞和同计算设置的 clean-slab 总能。若现有 clean slab 经过结构、计算参数和热修正一致性核验后可复用，则只需新增 13 个 slab+C* 计算；否则 clean slab 也需补算或提供可核验的同源输出。
- 两类状态的温度/Gibbs 修正定义及来源；若形成 333.15 K Gibbs 形成能，修正必须在 slab+C* 与 clean slab 间一致，且说明是否包含振动/熵项。
- `μC` 的原始来源及可比性依据（参考相/孤立原子、自旋、泛函、赝势、数值设置和单位）。
- 每个数值的源文件、结构标识、输出能量字段/单元格和计算设置元数据。

空白 13 位点模板位于 `data/Cstar_13site_DFT_data_template.csv`；来源扫描明细位于 `data/Cstar_source_inventory.csv`。

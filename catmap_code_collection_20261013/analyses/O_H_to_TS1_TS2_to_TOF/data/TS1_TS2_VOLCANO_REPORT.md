# TS1_s + TS2_s 火山图与 CatMAP 网格核验

## 结论摘要

- 13 个严格基准位点按 `surface_name` 匹配，排除 Ti–Zr；温度为 333.15 K。
- 普通二次响应面可复现：样本内 R² = 0.7432571，RMSE = 4.19636（log10 TOF）。其数学峰为 TS1_s = −33.28304478 eV、TS2_s = −7.71378516 eV、预测 log10(TOF) = 0.60297816（TOF = 4.00847）。峰虽在坐标矩形内，但在催化剂凸包外；最近真实点为 Ti–Ni。因此这是样本外形状提示，不是已被催化剂点夹持的可实现最优位点。
- CatMAP 0.3.1 官方 `GeneralizedLinearScaler + SteadyStateSolver + MinResidMapper` 的 50×50 网格共求解 2,500 个节点，全部输出为正且有限，最大重新计算稳态残差 9.7910×10⁻⁷¹，小于输入容差 10⁻⁷⁰。离散网格最大点为 TS1_s = −33.31473488 eV、TS2_s = −7.67349876 eV、log10(TOF) = 4.82189965（TOF = 66,358.97）；该点为内部离散局部最大值（周围 8 个网格节点均较低），但没有进行连续域优化。
- CatMAP 官方 `VectorMap` 的 400×400 图/数据是基于上述 50×50 已收敛解，经 `ReactionModel.map_to_array` 三次插值生成；不是 160,000 次独立稳态求解。插值图最大点为 (−33.31019165, −7.64736189) eV，log10(TOF) = 4.83203978。
- 两种峰坐标相近，但预测活性相差约 4.22 个 log 单位；更重要的是，经验模型峰在催化剂凸包外，CatMAP 网格的活性量级远高于严格基准数据。数值收敛只证明该标度模型网格上的方程求解达到了容差，不等价于描述符标度、外推或物理活性已获验证。

## 数据与模型

输入快照：

- `data/energies.txt`：SHA256 `DA3DEFB584E215BA41143D6C17A4F23F44FDB3091F4861965B7790CDE6B00D31`。
- `data/matched_data.csv`：SHA256 `79638B616D58FD4FBF2C2B06B30752D4D4E1DBE58B19BD99EA38788D12A7D4A0`。
- TOF 与 descriptor 通过 surface_name 连接；13 个状态均来自 333.15 K 严格收敛基准，Ti–Zr 不纳入。原始形成能、NEB 数据、正式基线及六步机理未修改。

CatMAP 网格沿用六步网络及严格基准储库：C6H12 = 1.0、H2O2 = 0.185、H2O = 0.815、C6H12O = 1e−20；333.15 K、`GeneralizedLinearScaler`、`SteadyStateSolver`、`MinResidMapper`、mpmath 75 位、容差 1e−70、TS 标度模式 `initial_state`，并使用官方 `avoid_scaling=True`。依据本机源码并通过隔离模型探针，13 个真实描述符锚点上的 91/91 个非空网络态输入能量（7 态×13 位点）均逐项恢复；非锚点处 5 个非描述符网络态均按线性 scaler 预测返回，最大数值差约 7.1×10⁻¹⁵ eV。两描述符为 `TS1_s` 和 `TS2_s`，范围分别为 [−34.566395, −32.451521] eV 与 [−7.921799, −4.880121] eV。正式 `.mkm`、运行器、探针及日志均随审核包保存。

## 图表解释

经验图包括完整矩形 400×400 二次响应面等高线、3D 面及穿过解析拟合峰的两个方向剖面；不作凸包遮罩，不改拟合系数。经验 R² 与 RMSE 是同一 13 点上的样本内结果，不能据此推断外推准确性。

CatMAP 图包含实际 50×50 求解节点图和官方 VectorMap 400×400 插值图；图中叠加 13 个基准催化剂点与标签、实际求解节点最大值，以及（VectorMap 图中）插值最大值。最近峰位的实测催化剂点为 Ti–Ni：经验峰的标准化二维距离 0.6295；CatMAP 50×50 峰的标准化二维距离约 0.56。图中催化剂点是基准数据位置，背景是标度模型的活性预测，二者不可混作同一批重新求解结果。

## 审核限制

1. CatMAP 数值节点通过严格稳态残差检查，但连续图中的绝大多数坐标由两个能量描述符的标度关系生成；这不是逐催化剂的原始 DFT/NEB 计算。
2. 400×400 VectorMap 是官方插值结果；可用于绘图/Origin 网格，不应表述为 160,000 个独立收敛解。
3. 经验响应面峰在观测凸包外，且模型的 TOF 数值与严格基准相差明显；两者均为探索性结果，不构成新的正式 TOF、催化剂排序或已验证机理结论。
4. 输入形成能的统一物理参考及热力学可信度不在本轮重审范围；此处没有借求解收敛来替代该项科学验证。

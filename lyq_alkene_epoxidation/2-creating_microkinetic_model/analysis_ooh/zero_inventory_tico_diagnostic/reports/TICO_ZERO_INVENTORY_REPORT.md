# Ti–Co 八步 CatMAP 零库存稳态诊断

## 结论与证据等级

在严格满足原始八步机理两条库存不变量的七维可行子空间内，使用 CatMAP 0.3.1 的反应速率表达式和稳态函数，获得一个高精度稳态候选。它通过表面稳态残差、八步净通量闭合、气相/表面计量重构、位点总和、非负覆盖度及不同数值初猜复现检查，并在零库存子空间局部稳定性数值诊断中所有特征值均为负。

该结果是**受约束子空间中的局部稳定数值稳态候选**，不是洁净表面初态的全局动力学可达性证明，也不证明其为唯一稳态分支。该根几乎被烯烃占据（`C6H12_s ≈ 0.989535`），产物 TOF 极低（约 `1.32368×10⁻³⁶ s⁻¹`）；应保留为 provisional，不应替换正式结果或直接用于 OOH–TOF 拟合。

## 计算边界与方法

- 使用本机 CatMAP 0.3.1；模型取自原始 `alkene_epoxidation.mkm`，能量取自原始 `energies_dft_neb.txt`。
- 温度 333.15 K；浓度模式及有效储库输入保持原值：C₆H₁₂ 1.0、H₂O₂ 0.185、H₂O 0.815、C₆H₁₂O 1e-20；冻结气相和吸附态热力学修正，避免重复施加热修正。
- CatMAP 官方速率常数、反应速率表达式及稳态残差函数保持不变。外层只将九个稳定吸附物种限制在两条守恒关系对应的七维坐标中，并由坐标重构 Ha、Hb 与空位。
- 配置精度 360 位、容差 1e-260；候选根进行更高工作精度抛光，并以另一扰动数值初猜复算。
- 这不是 CatMAP 的物理初始条件积分。`get_steady_state_coverage(c0=...)` 中的 `c0` 是根求解初猜，不等同于从该覆盖度启动真实时间动力学。

## 根因复核

已有 Ti–Co 审计的 8 个合格根分布在 3 个采样簇中，但没有满足洁净空表面库存类的根。原始八步表面化学计量矩阵秩为 7（9 个稳定吸附态），存在两个独立守恒量：

```text
I1 = θ(Ha*) − θ(OOH*) − θ(OH*) − θ(O*)
I2 = θ(Hb*) − θ(O*)
```

洁净空表面属于 `I1=I2=0` 的库存类。历史 CatMAP 稳态求根没有在求解过程中约束这两个不变量，普通稳态根即使数值残差很小，也可能属于别的库存类。根因是稳态方程存在守恒零模/库存分支，而非单纯“精度不够”。本次把库存限制直接嵌入求解坐标，得到一个零库存候选；这不能反向证明旧的非零库存根可用于洁净表面 TOF。

覆盖度顺序为 CatMAP 稳定吸附物种；空位另列。完整精度值保存在 `data/tico_zero_inventory_root.json`。

- `I1 = 2.2634041064873e-571`；`I2 = 0`。
- 覆盖度总和 `=1`；覆盖度均非负。
- 最大独立表面残差绝对值 `=1.1848229142808e-100`；相对最大净通量残差 `=8.9509924121e-65`。
- 八步净速率均为 `1.3236777105111e-36`（CatMAP 当前速率单位约定下）；气相产物 C₆H₁₂O 的净 TOF 同值，`log10(TOF)=-35.8782177441901`。
- 八步循环相对通量差 `=8.9509924121e-65`；气相计量重构绝对误差为 0；表面计量重构最大绝对误差 `=2.3688175315e-100`。
- 七个零库存子空间局部稳定特征值均为负；最慢模约 `−1.1840e-13 s⁻¹`。这是局部数值稳定证据，不是全局可达性证明。
- 独立扰动初猜重放：覆盖度最大绝对差 `2.3937e-76`，`log10(TOF)` 差 `5.1635e-49`；重放通过既有稳态质量门控。

## 数值尝试记录

六个确定性尝试均保留于 `data/solver_attempts.json`。较差初猜分别因边界/雅可比奇异，或残差未达相对门控而被拒绝；仅高精度抛光候选通过门控。失败初猜未被当作结果、未将失败解释为零 TOF，也未放宽验收门槛。

## DRC 与物理可达性

本轮未计算 DRC。CatMAP 0.3.1 官方 DRC 接口通过能量扰动后调用常规未约束稳态求解；它不会自动保持这里的零库存类及同一分支。因此直接套用该接口不能保证是此根的 DRC。下一步须先验证从洁净空表面出发的真实时间动力学可达性，或取得等价的分支/吸引域证据；之后才可在扰动前后保持相同库存约束和分支的条件下设计 DRC 验证。

## 尚未解决的科学限制

1. 当前仅是 Ti–Co 单个位点的约束稳态验证；没有开展多位点计算。
2. 局部稳定不等同于从洁净空表面可达，尚需真实时间积分/吸引域证据；有限时间停滞也不能单独证明稳态。
3. NEB 态与八步反应坐标的结构对应仍需原始结构证据；尤其 NEB2 的温度/热修正证据未由本计算补齐。故该根及 TOF 仍是模型条件下的 provisional 数值。
4. 未运行官方 DRC、OOH–TOF 拟合、13 位点重算或描述符网格。
